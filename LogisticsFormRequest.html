If the customer received the item but it's missing within the pack, that's a reorder. Example: A dozen of pens arrive with 11 inside the box.
Another example, customer should have gotten one box with two items, they got the one box, but only one item – that’s a mixed carton.

Before continuing to the form on the next page, you will need the following information.  Make sure you have all of these before hitting continue (or whatever this button will say):

  • Company Name and/or Delivery Location Name (Delivery Location Name is usually most helpful as that’s what the driver sees)
  • Account Number
  • Sales Order Number (if you have more than one, please submit them as separate requests)
  • Shipping Address (full address required – street address, city, state, and zip code)
  • Contact name and phone number (who is reaching out about this issue?)
  • Warehouse delivering the order
  • Route the order is on (check to make sure it’s not different in the delivery tracking window)
  • Driver’s name and phone number (from today’s POA)
