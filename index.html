New Logistics (Text-a-Driver)

Secure Logistics Request Portal

Submitting a Logistics Request requires you to have checked several different areas in the system and you'll need to enter a lot of information, so let's make sure you have taken all the required steps and have what you need:

FIRST, please review this message as these items will NOT be submitted in this form:

  • If the customer received the item but it's missing within the pack, that's a return and reorder.
    Example: A dozen pens were ordered, but arrive with 11 inside the box. Another example, customer should have gotten one box with two items (lets say pens and staples), they got the one box, but only one item – that's a mixed carton. Both of these examples should not go to the driver nor logistics – process a return and reorder.
  • If the item is ON PO QTY, it should go to purchasing.
  • If the item is Backordered, try and find an alternative with our quote team and/or reach out to purchasing for more information.
  • If it's Release Review, please follow this KB: Release Review

SECOND, what steps have you already taken to ensure reaching out to logistics is the correct next step?

This is the KB on the logistics process: Logistics Process

If you have followed these steps and determine you need to reach out to logistics, then please continue to the information below.

FINALLY, before continuing to the form on the next page, you will need the following information.

Make sure you have all of these before hitting the Next button below:

  • Company Name and/or Delivery Location Name (Delivery Location Name is usually most helpful as that's what the driver sees)
  • Account Number
  • Sales Order Number (if you have more than one, please submit them as separate requests)
  • Shipping Address (full address required – street address, city, state, and zip code)
  • Contact name and phone number (who is reaching out about this issue?)
  • Warehouse delivering the order
  • Route the order is on (check to make sure it's not different in the delivery tracking window)
  • Driver's name and phone number (from today's POA)

Hi. When you submit this form, the owner will see your name and email address.
