Methodology & Definitions
How the dashboard calculates executive indicators

Review Quality Index

Weighted average of all rating-bearing review fields, translated from Below = 1, Meets = 2, Exceeds = 3 and normalized to a 0–100 scale. EOM overall rating and extended review category ratings are both included where available.

Operational PBI profile

Any numeric field returned by Power BI is automatically summarized. In addition, named metrics from the source app are surfaced explicitly so leadership can track the exact KPI families in use today.

Risk logic

Insights call out below-expectation concentration, low adherence, under-covered departments, and manager segments with elevated review volume but weak average scores.

This SPA is intentionally self-contained and built from the original Performance Review Portal architecture. If any Power BI column names differ in production, update the explicit metric map in ORIGINAL_METRIC_GROUPS or continue using the dynamic numeric profiler without code changes.
