What this portal does

When reviews exist, the portal shows executive review intelligence. When reviews do not exist, it automatically pivots into operational mode using Login/Logout and Avaya data so leadership still gets a clean monthly story.

Review mode
Review quality, review mix, category ratings, coverage by department and manager, plus operational overlays.
Operational mode
Attendance coverage, logged hours, adherence, call throughput, department/manager accountability, and executive summaries powered only by Power BI.
Aligned to the working sister app
Uses the same Microsoft sign-in, Dataverse org, Power BI datasets, tunnel pattern, and employee name matching strategy.

Executive Snapshot

Scope by month, department, manager, employee, and review type. The portal dynamically chooses review-led or operations-led reporting depending on whether Dataverse review records exist for the current slice.

Methodology & Definitions
How the executive portal chooses its story and calculations

Review Quality Index

Built from rating-bearing review fields across EOM / EOQ and extended reviews, normalized to a 0–100 scale when review records exist.

Operations Mode

If the current slice has no Dataverse reviews, the portal pivots cleanly to attendance, logged hours, adherence, and throughput reporting based on the sister app’s Power BI datasets.

Source Alignment

This file uses the same Dataverse org, Power BI datasets, Azure AD application, tunnel URL, employee name matching logic, and review field families found in the working sister app.

If production column names drift slightly, the dynamic Power BI profiling panels will still work. The explicit metrics and review mappings are based on the sister app’s live field usage and dataset identifiers.
