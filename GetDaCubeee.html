Hello Team Member,

Submitting a Logistics Request requires you to have checked several different areas in the system. You’ll also need to enter a lot of information, so let’s make sure you have taken all required steps and have what you need.

1FIRST: These items are not submitted here

Stop and redirect if one of these applies. This form should only be used when logistics is the correct next step.
  • If the customer received the item but it is missing within the pack, that is a reorder.
    Example: A dozen pens arrive with only 11 inside the box. Another example: the customer should have received one box with two items; they got the one box, but only one item — that is a mixed carton.
  • If the item is ON PO QTY, it should go to Purchasing.
  • If the item is Backordered, try to find an alternative with the Quote Team and/or reach out to Purchasing for more information.
  • If it is Release Review, follow this KB: Release Review.

SPSharePoint Process Summary

Never give customer warehouse employee contact info. Also remember to link the warehouse email in Dynamics 365 and add notes to the account in CSW.
  • Open returns: Email the correct returns contact. If no response after two email attempts, submit to Logistics by end of day/shift.
  • Delivery window: Do not reach out to managers/supervisors about missing items if still within 1–3 business days of manifest date; Text-a-Driver may still be used for missing items within the correct timeframe.
  • Driver call script: “Hi, this is ____ with WB. I'm calling about [location] missing [item description]. Is this still on the truck?”
  • Warehouse email: Use the correct contact for the situation: returns, goldstar supervisor, or picking/packing contact.
  • Route changes: UPS route changes use the Logistics form. WB Mason route-to-route changes are updated in the main table form addresses tab, and must include current route, new route, and branch approver.
  • Damage/driver incident: Gather claimant name, phone, email, incident date, and details; send to your manager first.
